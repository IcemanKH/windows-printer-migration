# Windows 打印机备份与恢复工具

把旧 Windows 电脑上的**打印机驱动和配置**备份出来，再在新电脑上还原，用于换机、重装系统时的打印机迁移。

工具版本：`1.0.0` ｜ 只使用 Windows 自带组件，不需要安装任何第三方软件。

---

## 一、功能与适用场景

### 核心功能

| 阶段 | 做什么 |
| --- | --- |
| **备份**（旧电脑） | 列出本机打印机 → 用户勾选要备份的 → 用系统自带 `pnputil` 导出驱动包 → 校验驱动身份、SHA256 完整性、数字签名 |
| **打包**（旧电脑） | 备份完成后，自动把「恢复入口 BAT + 核心脚本」复制进备份目录，使备份目录自带恢复程序 |
| **恢复**（新电脑） | 自动定位备份数据 → 核对 SHA256 校验清单 → 检查架构兼容性与签名 → 安装驱动 → 重建打印机队列 → 检查网络端口 → 可选打印测试页 |

### 三级备份结论

备份结束时，程序对每台打印机给出三级结论，并在最后汇总：

| 结论 | 含义 |
| --- | --- |
| **完整备份** | 驱动包已导出并通过身份 / 完整性 / 签名校验，新电脑可自动安装 |
| **部分备份** | 没有驱动文件或需要人工一步（共享打印机、缺 IP 的网络打印机、USB 需重新插线），程序会给出具体手动步骤 |
| **不可迁移** | 旧电脑上该驱动没有可导出的 INF（厂商安装程序直接注册的旧式驱动），必须在新电脑上安装厂商驱动包 |

总体结论分为 **成功 / 部分成功 / 失败**：只有全部打印机都是「完整备份」才算成功。

### 适用场景

- 公司电脑 → 个人电脑 的打印机迁移
- 换新电脑、重装系统后恢复打印机
- 目标电脑无法联网下载驱动的环境（用 U 盘搬驱动）

## 二、运行环境与依赖

- **操作系统**：Windows 10 / Windows 11（32 位、64 位、ARM64）。其他 Windows 版本未经验证。
- **PowerShell**：Windows PowerShell 5.1（Windows 10 / 11 自带）。脚本以 `#Requires -Version 5.1` 声明。
- **依赖**：全部为 Windows 自带组件，无需另外安装
  - `pnputil.exe` —— 驱动包导出 / 导入
  - `PrintManagement` 模块 —— `Get-Printer` / `Add-Printer` 等
  - `printui.dll` —— 发送测试页
  - `Get-AuthenticodeSignature` —— 驱动数字签名校验
- **权限**：备份时导出驱动、恢复时安装驱动都需要管理员权限，程序会自动弹出 UAC 提权窗口。

## 三、文件说明

### 本仓库中的源文件

| 文件 | 用途 |
| --- | --- |
| `01_备份打印机.bat` | 备份入口，在**旧电脑**上双击运行 |
| `02_恢复打印机.bat` | 恢复入口，在**新电脑**上双击运行 |
| `Printer_Migration.ps1` | 核心脚本，由上面两个 BAT 调用，负责具体的备份与恢复操作 |

> 三个文件必须放在**同一个目录**下。两个 BAT 都会检查核心脚本是否就在自己旁边，找不到会直接报错并停止。

### 备份目录内自动生成的文件

运行 `01_备份打印机.bat` 后，会在同目录下生成 `Printer_Backup` 文件夹。注意：**`02_恢复打印机.bat` 和核心脚本会被复制进去一份**，所以备份目录本身就能在新电脑上直接运行：

```text
Printer_Backup/
├── 02_恢复打印机.bat      ← 备份时自动复制进来（新电脑的恢复入口）
├── Printer_Migration.ps1  ← 备份时自动复制进来（核心脚本）
├── Printers.json          ← 备份清单：打印机、端口、驱动包对应关系
├── 配置清单.txt           ← 人工可读的备份内容清单
├── 恢复说明.txt           ← 备份目录自带的新电脑操作说明
├── Checksums.json         ← SHA256 校验清单（机器可读）
├── 校验清单.txt           ← SHA256 校验清单（人工可读）
├── Drivers/               ← 导出的驱动包（每套驱动一个 oemN 子目录）
└── Logs/                  ← 备份 / 恢复日志
```

> 备份目录里**没有** `01_备份打印机.bat`——备份只在旧电脑做一次，新电脑只需要恢复入口。

## 四、操作步骤

### 第 1 步：在旧电脑上备份打印机

1. 把本仓库的三个文件放到旧电脑的**同一个文件夹**里（例如桌面新建 `打印机备份`）。
2. 双击 `01_备份打印机.bat`。
3. 如果弹出 UAC 提示，选择「是」。
4. 程序会列出本机所有打印机，按提示输入要备份的编号。
   - 支持单个：`2`
   - 支持多个：`1,3,5`（中英文逗号、空格皆可）
   - 支持区间：`1-3`
   - 支持全部：`all`
5. 等待程序导出驱动包并完成校验（窗口会显示每一步进度）。
6. 记下最后的备份结论（完整 / 部分 / 不可迁移），窗口里也会显示备份目录路径。
7. 按回车键关闭窗口。

### 第 2 步：用 U 盘 / 移动硬盘把备份搬到新电脑

1. 找到上一步生成的整个 `Printer_Backup` 文件夹。
2. **把整个文件夹一起复制**到 U 盘或移动硬盘。
   - 必须先压缩成 ZIP 再复制也可以，关键是**不要只挑里面几个文件**。
   - 恢复程序会核对 SHA256 校验清单，缺文件会报错。
3. 在新电脑上，把整个 `Printer_Backup` 文件夹复制到**本地磁盘**（例如桌面）。
   - 建议不要直接在 U 盘上运行恢复，也不要放在网络共享目录里；
   - 目标位置要有**写入权限**，因为恢复过程要写日志。

### 第 3 步：在新电脑上恢复打印机

1. 打开复制过来的 `Printer_Backup` 文件夹。
2. 双击里面的 `02_恢复打印机.bat`。
3. 如果弹出 UAC 提示，选择「是」（安装驱动必须提权）。
4. 程序会自动找到 `Printers.json`，核对 SHA256 校验清单，并检查本机系统架构与驱动签名。
5. 对每一台打印机，按提示处理：
   - **有可导出的驱动包** → 自动安装驱动，并重建端口和打印队列；
   - **网络打印机（备份里有 IP）** → 先显示端口创建计划，确认后创建 TCP/IP 端口和队列，并做一次连通性检查（只提示，不阻断）；
   - **USB 打印机** → 提示插好 USB 线并开机，然后检测系统是否已识别；
   - **备份信息不足** → 不自动创建，直接给出对应的手动步骤。
6. 打印机创建成功后可选择是否打印一张测试页（输入 `Y` / `N`）。
7. 查看最后的恢复结果汇总（**已恢复 / 驱动已装 / 需手动处理**）。
8. 按回车键关闭窗口。

## 五、管理员权限与执行策略

### 管理员权限

- 备份和恢复都**需要管理员权限**：程序检测到权限不足时会自动请求提权（标准 UAC 窗口）。
- 如果 UAC 窗口被取消导致提权失败，可以右键 BAT → **以管理员身份运行**。
- 如果本机执行策略被组策略设为 `Restricted` 或 `AllSigned`，提权后的新窗口**同样无法运行脚本**。此时程序会明确提示找 IT 放行或以签名方式分发，**不会绕过该策略**。

### 执行策略（ExecutionPolicy）

- 程序**从不使用** `-ExecutionPolicy Bypass`，也不修改任何系统策略。
- 只有当本机策略是 Windows 默认值（`Restricted` / `Undefined`）时，才为**当前进程**附加 `-ExecutionPolicy RemoteSigned`——它仍然会拦截下载来源 / 被阻止的脚本。
- 如果策略由组策略下发（常见于公司电脑），Windows 会忽略该参数，**公司设置始终优先**。
- 手动放行（只对当前用户生效，且可能被组策略拦截）：

  ```powershell
  powershell -NoProfile -Command "Set-ExecutionPolicy -Scope CurrentUser RemoteSigned"
  ```

### 文件被「阻止」（来自网盘 / 下载）

右键 `Printer_Migration.ps1` → **属性** → 勾选「解除锁定」→ 确定。

## 六、常见错误与处理

| 现象 | 原因与处理 |
| --- | --- |
| `Printer_Migration.ps1 was not found next to this file` | 三个文件没放在同一目录。把 `01_备份打印机.bat`、`02_恢复打印机.bat`、`Printer_Migration.ps1` 放回同一个文件夹。 |
| `running scripts is disabled on this system` | 执行策略拦截。按上一节「执行策略」处理，或请 IT 放行。 |
| `Printers.json was not found in this folder` | 没有复制完整的 `Printer_Backup` 文件夹。请重新完整复制一次。 |
| UAC 窗口被取消、提权失败 | 右键 BAT → 以管理员身份运行。 |
| 恢复时提示备份文件哈希不一致 | 备份文件已损坏或被改动，程序会**停止安装该驱动包**（不会用不完整的驱动去装）。请从旧电脑重新完整备份。 |
| 网络打印机提示「当前没有响应」 | 打印机未开机或不在同一网络。可先创建端口和队列，之后再确认连接。 |
| 共享打印机没有恢复 | 共享打印机依赖公司网络和账号权限，程序**不会自动连接**，需要手动添加。 |
| 某台打印机提示「不可迁移」 | 旧电脑上该驱动是厂商安装程序直接注册的旧式驱动，没有可导出的 INF。在新电脑上安装厂商驱动包即可。 |
| USB 打印机没有检测到 | 插好 USB 线并开机，等系统识别出 `USB001` 之类的端口，再重新运行恢复。 |
| 测试页没有打出来 | 程序只能把任务发送到打印队列，无法确认纸张是否真的打印出来。请检查打印机电源、纸盒和队列状态。 |
| 恢复后默认打印机变了 | 程序会尝试把默认打印机还原为恢复前的状态；若被系统改动会给出提示，可手动设置。 |

## 七、已知限制

1. **不保证所有打印机和驱动都能成功恢复。** 只有能通过 `pnputil` 从 Windows 驱动库导出 INF 驱动包的打印机才能自动恢复。
2. **不导出厂商安装程序。** 只导出 Windows 驱动库里的驱动包；厂商「安装向导」式驱动（没有可导出 INF）会被标记为不可迁移。
3. **不支持跨架构恢复。** 32 位 → 64 位、x64 → ARM64 的驱动通常无法安装，程序会逐台检查兼容性并给出警告。
4. **共享打印机不会自动连接。** 需要公司网络与账号权限，由用户手动添加。
5. **网络打印机需要有效 IP。** 备份里没有 IP 的网络打印机（如 WSD 端口）需要在新电脑上重新搜索设备。
6. **不覆盖已有打印机。** 新电脑上若已有同名打印机，程序不会改动它，也不会创建冲突端口。
7. **不删除任何驱动、不修改默认打印机、不自动重启电脑。**
8. **不使用 `/force`。** 不绕过驱动签名校验；签名校验失败的驱动不会被安装。
9. **只处理用户选中的打印机。** 备份时不会全量导出驱动库，也不导出与所选打印机无关的驱动。

## 八、安全注意事项

- **只用 Windows 自带组件。** 不下载、不安装任何第三方工具。
- **不使用绕过手段。** 不用 `-ExecutionPolicy Bypass`，不用 `/force`，不绕过驱动签名与安全策略。
- **不修改系统策略。** 执行策略由 Windows 和组策略决定，程序只读取，不写入。
- **备份目录含敏感信息。** 生成的 `Printer_Backup` 文件夹中会包含：
  - 打印机名称、IP 地址、端口与共享路径；
  - 旧电脑的**计算机名和用户名**（记录在 `Printers.json` 与 `配置清单.txt` 中）；
  - 驱动包文件以及备份 / 恢复运行日志。

  请把备份目录当作内部资料保管，**不要公开上传或分享**。
- **本仓库不含任何真实备份数据。** 仓库只包含三个脚本和文档；`.gitignore` 已排除备份产物、驱动文件与日志。

## 九、自检

脚本内置只读自检，用于确认运行环境正常：

```bat
01_备份打印机.bat -SelfTest
```

或：

```bat
02_恢复打印机.bat -SelfTest
```

自检**不安装驱动、不修改打印机配置、不发送测试页**；其中一个用例会调用「创建打印机端口」的逻辑，目的是确认它在遇到同名打印机时**拒绝创建**，并会复查系统中没有真的新增端口。

输出每一项 `[PASS]` / `[FAIL]`，最后给出通过 / 失败计数；有失败时退出码为 1。
