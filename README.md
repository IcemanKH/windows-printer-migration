# 🖨️ Windows 打印机驱动极简备份与恢复

> 两个 BAT + 一个 PowerShell，把旧电脑的打印机驱动和配置搬到新电脑。
> **够小、够简单、不用装任何东西。**

`v1.0.0` ｜ Windows 10 / 11 ｜ PowerShell 5.1+

---

## ✨ 为什么用它

- **超小**：只有 3 个文件，复制即用
- **零依赖**：只用 Windows 自带组件，不装第三方软件
- **极简**：双击 BAT → 选打印机 → 备份；拷到新电脑 → 双击恢复
- **自带恢复入口**：备份目录里自动带上恢复 BAT 和核心脚本
- **严格校验**：驱动身份 + SHA256 + 数字签名，不合格不装
- **安全克制**：不用 `Bypass`，不用 `/force`，不改系统策略，不覆盖已有打印机
- **结论清楚**：每台打印机明确标注「完整备份 / 部分备份 / 不可迁移」

---

## 🎯 适合这些场景

- 新人入职，快速给新电脑补上打印机驱动
- 电脑重装系统后，恢复打印机
- 换新电脑，旧机驱动搬家
- 新电脑不方便联网，用 U 盘离线恢复

## 📁 文件说明

把下面 **3 个文件放在同一目录**：

| 文件 | 用途 |
| --- | --- |
| `01_备份打印机.bat` | 旧电脑双击运行 |
| `02_恢复打印机.bat` | 新电脑双击运行 |
| `Printer_Migration.ps1` | 核心脚本，由两个 BAT 调用 |

> ⚠️ 三个文件必须同目录。BAT 会检查核心脚本是否在身边，找不到直接报错退出。

双击备份入口后，程序会先打印标题栏、程序目录与备份输出目录：

![备份入口启动界面](docs/images/backup-entry.png)

> 本文所有截图均使用**演示数据**（演示打印机名称、演示计算机名与 RFC5737 文档用 IP），非真实环境。

## 🚀 三步搞定

### 1️⃣ 旧电脑：备份

双击 `01_备份打印机.bat` → UAC 允许 → 选择要备份的打印机：

```text
2          # 单个
1,3,5      # 多个（中英文逗号、空格皆可）
1-3        # 区间
all        # 全部
```

![选择要备份的打印机](docs/images/backup-select.png)

备份完成后，同目录会生成 `Printer_Backup/`：

```text
Printer_Backup/
├── 02_恢复打印机.bat      ← 自动复制，新电脑恢复入口
├── Printer_Migration.ps1  ← 自动复制，核心脚本
├── Printers.json          ← 备份清单
├── 配置清单.txt
├── 恢复说明.txt
├── Checksums.json         ← SHA256 校验清单
├── 校验清单.txt
├── Drivers/               ← 导出的驱动包
└── Logs/
```

每台打印机都会给出三级结论，并在最后汇总：

![备份结果汇总](docs/images/backup-result.png)

### 2️⃣ 搬运

把整个 `Printer_Backup` 文件夹复制到 U 盘 / 移动硬盘，再复制到新电脑**本地磁盘**（例如桌面）。

> 不要只挑几个文件；不要直接在 U 盘或网络共享里运行恢复。

![备份目录结构](docs/images/backup-folder.png)

### 3️⃣ 新电脑：恢复

双击 `Printer_Backup\02_恢复打印机.bat` → UAC 允许 → 按提示处理：

- **有驱动包** → 自动安装驱动、重建端口和打印队列
- **网络打印机（有 IP）** → 显示端口创建计划，确认后创建 + 连通性检查
- **USB 打印机** → 提示插好线并开机，自动检测
- **信息不足** → 给出手动步骤

恢复前会先自动定位备份数据、核对 SHA256 校验清单、检查架构与签名：

![恢复入口与完整性校验](docs/images/restore-entry.png)

完成后可选打印测试页，并查看汇总：**已恢复 / 驱动已装 / 需手动处理**。

![恢复结果汇总](docs/images/restore-result.png)

## 🧩 备份结论

| 结论 | 含义 |
| --- | --- |
| ✅ **完整备份** | 驱动已导出，并通过身份 / 完整性 / 签名校验，可自动安装 |
| ⚠️ **部分备份** | 缺驱动文件或需人工一步（共享打印机、缺 IP 的网络打印机、USB 需重新插线） |
| ❌ **不可迁移** | 旧驱动没有可导出的 INF，需在新电脑安装厂商驱动包 |

> 只有全部打印机都是「完整备份」，总体结论才是 **成功**。

## 🛠️ 运行环境

- Windows 10 / 11（x86 / x64 / ARM64）
- Windows PowerShell 5.1（系统自带）
- 需要管理员权限，程序会自动弹 UAC 提权
- 依赖全部为 Windows 自带组件：`pnputil`、`PrintManagement`、`printui.dll` 等

---

## 🔐 权限与执行策略

- 备份、恢复都需要管理员权限；UAC 被取消可右键 BAT →「以管理员身份运行」
- **从不使用** `-ExecutionPolicy Bypass`，**从不修改**系统策略
- 仅当策略为 Windows 默认值时，为当前进程附加 `RemoteSigned`；组策略始终优先
- 如果脚本被「阻止」：右键 `Printer_Migration.ps1` → 属性 → 勾选「解除锁定」

## ❓ 常见问题

| 现象 | 处理 |
| --- | --- |
| `Printer_Migration.ps1 was not found` | 三个文件不在同一目录 |
| `running scripts is disabled` | 执行策略拦截，参考上一节或请 IT 放行 |
| `Printers.json was not found` | 备份目录没复制完整 |
| 哈希不一致 | 备份损坏，程序拒绝安装，请重新完整备份 |
| 网络打印机无响应 | 打印机未开机或不在同一网络，可先建队列稍后确认 |
| 共享打印机没恢复 | 依赖网络和账号权限，不自动连接，需手动添加 |
| 提示「不可迁移」 | 在新电脑安装厂商驱动包 |
| USB 未检测到 | 插好线开机，等系统识别出 `USB001` 后重跑 |
| 测试页没打出来 | 程序只能发送任务，请检查打印机电源、纸盒和队列 |
| 默认打印机变了 | 程序会尝试还原，被系统改动时会提示，可手动设置 |

## ⚠️ 已知限制

1. 只有能从 Windows 驱动库导出 INF 的驱动才能自动恢复
2. 不导出厂商安装程序；无 INF 的驱动会被标记为不可迁移
3. 不支持跨架构恢复（32↔64、x64↔ARM64 通常无法安装）
4. 共享打印机不自动连接
5. 网络打印机需有效 IP；WSD 端口需重新搜索设备
6. 不覆盖已有同名打印机
7. 不删除驱动、不改默认打印机、不自动重启
8. 不使用 `/force`，签名失败即拒绝安装
9. 只处理用户选中的打印机，不全量导出驱动库
